Android NumPy quad-precision floating-point runtime

This NumPy build links only quad-precision soft-float arithmetic, conversion,
comparison and exception-handling objects from the Android-hosted GCC4.9
runtime. It includes no GCC unwinder and adds no shared Fortran runtime.
The source headers contain LGPL2.1-or-later with an additional unlimited-linking
permission; machine-specific runtime support uses GPL3-or-later with GCC Runtime
Library Exception3.1. Original license texts follow. Exact AOSP prebuilt input
hashes, member lists and GCC source revisions are recorded in quad-runtime/
provenance.json and exact-source-provenance.json in the native build inputs.

The helpers restore the floating exception flags required by NumPy longdouble
error handling; the rest of NumPy is compiled/linked with NDK27 and16KB layout.
